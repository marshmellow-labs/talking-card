Saved reference patterns

Patterns are saved in this browser only. Export them to share a trained library with family; importing merges the references. For everyone to receive the same patterns automatically, include an exported shared-patterns.json in the deployed site folder.

Camera and hosting

Browser camera access generally requires HTTPS or http://localhost. Opening index.html directly as a file:// page is not a dependable way to use the camera. GitHub Pages and Vercel provide HTTPS. Once hosted, open the page and use your browser's “Add to Home screen” / “Install app” option. Offline use works after the site has been loaded and cached. No images are uploaded.

This app uses built-in Canvas pixel processing (no external CV download), including contrast thresholding and row/column projections. It does not yet decode the manufacturer's numeric scheme; it matches learned optical signatures.
